# Framer Canvas Code Component Master Template

This document provides the authoritative, production-ready **Canvas Code Component Master Template** generated by `framer-canvas-codegen` and deployed to the Framer canvas via `framer.createCodeFile`.

It seamlessly integrates:
1. **Strict Zero Inline CSS**: All canvas styling resides in a consolidated external CSS string template (`cssContent`) injected via `<style>`.
2. **Property Controls (`addPropertyControls`)**: Exposes visual controls directly in Framer's sidebar.
3. **Dual-Layer Pro-Lock**: Renders the Frosted Pro Lock Banner when locked.
4. **1-Instance Trial Limit & Duplicate Protection**: Uses `window.__instances__` to block duplicate copies on canvas.
5. **Trial Watermark Badge & Automatic Removal**: Renders the company watermark during trial, automatically removed when paid.
6. **Strict Icon Standard**: Lucide React icons or Framer SVG icons only (Strictly Zero Emojis).

## 2. Key Architecture Standards for `framer-canvas-codegen`

1. **Auto-Patch Regex Compatibility**:
   - Every generated component must keep the exact signature:
     ```typescript
     const IS_LOCKED = (true|false);
     const IS_TRIAL = (true|false);
     // @plugin-lock-state: (locked|unlocked)
     // @plugin-trial-state: (trial|paid)
     ```
   - This ensures `enforceLockState` in `App.tsx` can rewrite the deployed file dynamically whenever the user signs in, trials, or purchases.

2. **Automatic Watermark Removal**:
   - When the user upgrades, `IS_TRIAL` becomes `false`.
   - The conditional `{IS_TRIAL && !IS_LOCKED && <div className="framefic-trial-watermark">...</div>}` automatically stops rendering the watermark badge immediately.

3. **1-Instance Trial Limit**:
   - `window.__instances__` tracks component mount IDs during trial. If a duplicate instance is pasted on canvas, it renders the `.framefic-duplicate-limit-container` instead of full output.
   - Post-purchase (`IS_TRIAL === false`), `isDuplicate` is bypassed and unlimited instances are unlocked.
