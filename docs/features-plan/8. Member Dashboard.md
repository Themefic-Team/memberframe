## 1. Executive Summary & Market Differentiator

When a member wants to view their renewal date, update a credit card, or download an invoice, existing Framer platforms create friction:

* **Competitor Weakness**: **Thenty** and **Outseta** force members away to external hosted portals (or generic iframe overlays) that clash visually with the creator's Framer website, feel disjointed, and erode brand trust.
* **The MemberFrame Advantage**: MemberFrame introduces `<MemberDashboard>`, a **100% canvas-native self-service portal**. It renders directly inside the Framer site with seamless theme inheritance (dark/light mode), zero code overrides, and direct gateway synchronization.

## 2. Member Experience & Tab Architecture

The `<MemberDashboard>` is organized into focused, modular segments:

```
┌────────────────────────────────────────────────────────┐
│  MEMBER DASHBOARD                                      │
├────────────────────────────────────────────────────────┤
│  [ Profile ]   [ Membership & Billing ]   [ Invoices ] │ <── Tab Navigation
├────────────────────────────────────────────────────────┤
│  Active Plan: Pro Member ($19/mo)                      │
│  Status: Active • Next Billing: Nov 12, 2026           │
│  Payment Method: Visa ending in 4242                   │
│                                                        │
│  [ Update Payment Method ]     [ Change Plan ]         │
└────────────────────────────────────────────────────────┘
```

### 2.1. Tab 1: Profile & Identity
* Displays member name, registered email, and subscription badge (`Free`, `Silver`, `Gold`, `VIP`).
* **Avatar Upload**: Supports drag-and-drop image uploads with client-side compression (max 2MB, JPEG/PNG/WebP validation) synced to the member record.
* Displays connected OAuth providers (Google, GitHub) with one-click unlink/link options.

### 2.2. Tab 2: Membership & Billing Management
* **Active Subscription Details**: Displays current plan name, billing cadence (`monthly`, `yearly`, `lifetime`), price in minor units, and next renewal date.
* **Lifetime Plan Handling**: A lifetime subscriber sees *"Lifetime Access — No further payments required"* with no renewal date and no cancellation button.
* **Secure Payment Method Update**:
  * Member clicks **"Update Payment Method"**.
  * `<MemberDashboard>` calls `POST /api/member/billing-portal-session` to generate a single-use, secure customer portal session directly on Stripe or Lemon Squeezy.
  * After updating card details or managing cancellation, the gateway returns the member back to the creator's site (`portalReturnUrl`).

### 2.3. Tab 3: Invoice & Receipt History
* Lists chronological invoice history: Date, Invoice Number, Amount Paid, and Payment Status (`Paid`, `Refunded`).
* **One-Click PDF Invoices**: Downloadable PDF receipt links. Protected by server-side signed URLs so members cannot inspect or guess other members' invoice IDs.

### 2.4. Tab 4: Team Seats (Conditional B2B Tab)
* Appears dynamically **only** if the member belongs to a tier with seat allocation (Feature F12).
* Renders team seat usage (e.g. *"7 of 10 seats filled"*), pending invite links, and seat revocation tools.

### 3.2. Data Contracts (`/api/member/*`)
```typescript
interface MemberBillingSummary {
  planName: string;
  billingInterval: "month" | "year" | "lifetime";
  amount: number; // Minor units (e.g., 1900 = $19.00)
  currency: string;
  nextBillingDate: number; // Unix timestamp
  paymentMethodSummary: string; // e.g. "Visa ending in 4242"
  invoices: Array<{
    id: string;
    date: number;
    amount: number;
    status: "paid" | "refunded";
    pdfUrl: string;
  }>;
}
```

### 3.3. Session Mid-Flight Expiry Handling
If a member leaves their dashboard open and their cookie expires, the component gracefully enters a signed-out state with an inline message:  
*"Your session has expired. Please sign in to access your dashboard."*  
It provides a direct CTA to trigger `<MemberAuth>` without crashing or losing unsaved form inputs.

## 4. Verification & Testing Checklist

### Automated Unit Tests
* **`test/memberDashboard.test.ts`**:
  * Assert that single-use billing portal URLs are invalidated after first use.
  * Assert that lifetime subscribers receive `lifetime: true` with hidden renewal dates and cancel buttons.
  * Assert that invoice IDs validate against the authenticated `memberId` to prevent cross-account enumeration.
  * Assert avatar upload validator enforces MIME type (`image/png`, `image/jpeg`, `image/webp`) and blocks files > 2MB.

### Manual Verification in Framer Canvas
1. Insert `<MemberDashboard>` onto a protected Framer `/account` page.
2. In the Framer Preview, log in as a test member:
   * Verify all enabled tabs (`Profile`, `Billing`, `Invoices`) render smoothly.
   * Verify avatar upload allows picking an image and displays the new thumbnail.
   * Click **"Update Payment Method"**: verify Stripe/Lemon Squeezy portal opens in a new tab.
   * Verify invoice download triggers PDF save.
3. Switch Framer workspace theme (Dark / Light): verify WCAG AA contrast compliance across all text, cards, and buttons.
